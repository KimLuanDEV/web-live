🔢 1. TẬP HỢP SỐ NGUYÊN

Các loại số:

  • Số tự nhiên: 0, 1, 2, 3, …
  • Số nguyên dương: 1, 2, 3, …
  • Số nguyên âm: −1, −2, −3, …
  • Số 0

Ký hiệu:

ℤ = { …, −3, −2, −1, 0, 1, 2, 3, … }

So sánh số nguyên:

  • Số dương > 0
  • Số âm < 0
  • Số âm nào xa 0 hơn thì nhỏ hơn

Ví dụ:

  • −5 < −2
  • 3 > −7

➕ 2. PHÉP CỘNG SỐ NGUYÊN

Quy tắc:

  • Cùng dấu: cộng giá trị tuyệt đối, giữ nguyên dấu
  • Khác dấu: lấy số lớn trừ số nhỏ, giữ dấu số lớn

Ví dụ:

  • (−3) + (−5) = −8
  • 7 + (−4) = 3

➖ 3. PHÉP TRỪ SỐ NGUYÊN

Quy tắc:

a − b = a + (−b)

Ví dụ:

  • 5 − (−3) = 8
  • (−4) − 6 = −10

✖️ 4. PHÉP NHÂN SỐ NGUYÊN

Quy tắc dấu:

  • (+) × (+) = (+)
  • (−) × (−) = (+)
  • (+) × (−) = (−)
  • (−) × (+) = (−)

Ví dụ:

  • (−3) × 4 = −12
  • (−5) × (−2) = 10

➗ 5. PHÉP CHIA SỐ NGUYÊN

Quy tắc: Giống quy tắc dấu của phép nhân.

Ví dụ:

  • 12 ÷ (−3) = −4
  • (−20) ÷ (−5) = 4

🍰 6. PHÂN SỐ

Dạng: a / b (b ≠ 0)

Phân số bằng nhau:

a/b = (a×n)/(b×n)

Rút gọn phân số:

Chia cả tử và mẫu cho ước chung lớn nhất.

Ví dụ:

  • 6/8 = 3/4
  • 2/3 = 4/6

➕➖ 7. CỘNG – TRỪ PHÂN SỐ

Cùng mẫu:

(a ± b) / c

Khác mẫu:

Quy đồng mẫu số rồi cộng / trừ.

Ví dụ:

  • 3/5 + 1/5 = 4/5
  • 1/2 − 1/3 = 1/6

✖️➗ 8. NHÂN – CHIA PHÂN SỐ

Nhân:

(a/b) × (c/d) = (a×c)/(b×d)

Chia:

(a/b) ÷ (c/d) = (a/b) × (d/c)

Ví dụ:

  • 2/3 × 3/5 = 2/5
  • 4/7 ÷ 2/3 = 6/7

📐 9. HÌNH HỌC CƠ BẢN

  • Điểm
  • Đường thẳng
  • Đoạn thẳng
  • Tia

Góc:

  • Góc nhọn (< 90°)
  • Góc vuông (= 90°)
  • Góc tù (> 90°)
  • Góc bẹt (= 180°)

Dụng cụ: thước thẳng, thước đo độ

🧠 10. TỔNG KẾT LỚP 6

  • Nắm vững số nguyên và quy tắc dấu
  • Thành thạo phân số
  • Biết đọc – vẽ – đo hình học cơ bản
