Thống kê toàn bộ công thức và kiến thức nền tảng Toán lớp 11

📐 1. CUNG – GÓC LƯỢNG GIÁC

Góc lượng giác: là góc có hướng, đo theo chiều ngược kim đồng hồ.

Đơn vị đo:

  • Độ (°)
  • Radian (rad)

Quy đổi:

  • 180° = π rad
  • 1 rad = 180° / π

📊 2. GIÁ TRỊ LƯỢNG GIÁC

Các tỉ số lượng giác:

  • sin x
  • cos x
  • tan x
  • cot x

Hệ thức cơ bản:

  • sin²x + cos²x = 1
  • tan x = sin x / cos x
  • cot x = cos x / sin x

📈 3. HÀM SỐ LƯỢNG GIÁC

  • y = sin x
  • y = cos x
  • y = tan x
  • y = cot x

Tính chất:

  • sin x, cos x: tuần hoàn chu kỳ 2π
  • tan x, cot x: tuần hoàn chu kỳ π

🧮 4. PHƯƠNG TRÌNH LƯỢNG GIÁC CƠ BẢN

Dạng thường gặp:

  • sin x = a
  • cos x = a
  • tan x = a

Ví dụ:

  • sin x = 1/2
  • cos x = 0

🧩 5. DÃY SỐ – CẤP SỐ CỘNG

Dãy số: tập hợp các số theo thứ tự.

Cấp số cộng:

  • uₙ = u₁ + (n − 1)d
  • Sₙ = n(u₁ + uₙ) / 2

Ví dụ:

  • 2, 5, 8, 11,… (d = 3)

🎲 6. HOÁN VỊ – CHỈNH HỢP – TỔ HỢP

Hoán vị:

Pₙ = n!

Chỉnh hợp:

Aₙᵏ = n! / (n − k)!

Tổ hợp:

Cₙᵏ = n! / (k!(n − k)!)

📊 7. NHỊ THỨC NEWTON

Công thức:

(a + b)ⁿ = Σ Cₙᵏ aⁿ⁻ᵏ bᵏ

Ví dụ:

  • (a + b)² = a² + 2ab + b²

🎯 8. XÁC SUẤT

Định nghĩa:

P(A) = số kết quả thuận lợi / tổng số kết quả

Tính chất:

  • 0 ≤ P(A) ≤ 1
  • P(A) + P(Ā) = 1

Ví dụ:

  • Xác suất tung đồng xu ra mặt ngửa = 1/2

📐 9. HÌNH HỌC KHÔNG GIAN CƠ BẢN

  • Điểm – đường thẳng – mặt phẳng
  • Quan hệ song song
  • Quan hệ vuông góc

Ghi nhớ: Hình không gian cần vẽ hình rõ ràng.
