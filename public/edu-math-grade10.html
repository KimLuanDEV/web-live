📐 1. MỆNH ĐỀ – TẬP HỢP

Mệnh đề: là câu khẳng định đúng hoặc sai.

Ký hiệu:

  • ∀ : với mọi
  • ∃ : tồn tại
  • ⇒ : kéo theo
  • ⇔ : tương đương

Tập hợp:

  • Tập số tự nhiên ℕ
  • Tập số nguyên ℤ
  • Tập số hữu tỉ ℚ
  • Tập số thực ℝ

📊 2. HÀM SỐ & ĐỒ THỊ

Hàm số: y = f(x)

Hàm bậc nhất:

y = ax + b (a ≠ 0)

Hàm bậc hai:

y = ax² + bx + c (a ≠ 0)

Đồ thị:

  • Bậc nhất → đường thẳng
  • Bậc hai → parabol

🧮 3. PHƯƠNG TRÌNH – BẤT PHƯƠNG TRÌNH

Phương trình bậc nhất:

ax + b = 0

Phương trình bậc hai:

ax² + bx + c = 0

Công thức nghiệm:

Δ = b² − 4ac

  • Δ > 0 → 2 nghiệm
  • Δ = 0 → 1 nghiệm
  • Δ < 0 → vô nghiệm

Bất phương trình:

  • ax + b > 0
  • ax + b < 0

📐 4. HỆ THỨC LƯỢNG TRONG TAM GIÁC

Định lý cosin:

a² = b² + c² − 2bc·cosA

Định lý sin:

a / sinA = b / sinB = c / sinC

➡️ 5. VECTOR

Vector: đoạn thẳng có hướng

Ký hiệu: →AB

Các phép toán:

  • Cộng vector
  • Trừ vector
  • Nhân vector với số

Ví dụ:

  • →AB + →BC = →AC

📐 6. TÍCH VÔ HƯỚNG CỦA HAI VECTOR

Công thức:

→a · →b = |a|·|b|·cosθ

Ứng dụng:

  • Tính góc giữa hai vector
  • Xét vuông góc

🔺 7. HÌNH HỌC PHẲNG

Quan hệ song song:

  • Hai đường thẳng song song
  • Đường thẳng song song mặt phẳng

Quan hệ vuông góc:

  • Hai đường thẳng vuông góc
  • Đường thẳng vuông góc mặt phẳng

📏 8. TAM GIÁC – TỨ GIÁC

Tam giác:

  • Tổng góc = 180°
  • Các đường đặc biệt: trung tuyến, phân giác, đường cao

Tứ giác đặc biệt:

  • Hình bình hành
  • Hình chữ nhật
  • Hình thoi
  • Hình vuông

🧠 9. TỔNG KẾT LỚP 10

  • Làm quen tư duy toán THPT
  • Nắm chắc hàm số & phương trình
  • Thành thạo vector & hình học
